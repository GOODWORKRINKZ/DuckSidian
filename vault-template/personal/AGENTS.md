# AGENTS.md — личное пространство сотрудника

Это схема **личного** vault'а одного сотрудника в DuckSidian. Бот ведёт его
в личных сообщениях (DM): сюда падают мысли, идеи, заметки по проектам,
голосовые (распознанные в текст), файлы и подборки фактов, собранные агентом
по запросу. Пространство изолировано: другие сотрудники и групповые чаты его
не видят, пока владелец явно не поделится артефактом (`/share`).

## Структура

```
users/<user_id>/
  AGENTS.md              ← этот файл
  index.md               ← каталог всех страниц wiki/ (агент обновляет)
  log.md                 ← append-only журнал операций
  raw/inbox/<date>.md    ← сырой журнал диалога (read-only для агента)
  raw/assets/<date>/     ← присланные файлы (read-only для агента)
  wiki/projects/<Slug>.md  ← проекты сотрудника (шаблон: _template.md)
  wiki/notes/<date>-<slug>.md     ← заметки, факты, наблюдения
  wiki/ideas/<date>-<slug>.md     ← идеи и гипотезы
  wiki/research/<date>-<slug>.md  ← подборки/фактчеки по запросу «посмотри/проверь/найди»
  wiki/queries/                   ← сохранённые ответы /ask
```

## Три слоя

1. **raw/** — источник истины: что человек реально сказал/прислал. Агент
   только читает. Каждая реплика в `raw/inbox/*.md` помечена `^msg-<id>`.
2. **wiki/** — синтез, который пишет агент: страницы проектов, заметки, идеи,
   подборки. Каждый факт — со ссылкой на источник
   (`[[raw/inbox/YYYY-MM-DD#msg-<id>]]`, URL, или `[[raw/assets/...]]`).
3. **Schema** — этот файл + `index.md` + `log.md`.

## Типы страниц и frontmatter

```yaml
---
type: project | note | idea | research | query
title: "Человекочитаемое название"
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: []
project: "[[Slug]]"      # для note/idea/research — к какому проекту относится (опц.)
status: active           # только для project: active | paused | done
---
```

- `wiki/projects/<Slug>.md` — создаётся из `wiki/projects/_template.md`.
  Секции: Цель, Текущий статус, Задачи, Идеи, Решения, Заметки, Артефакты,
  История. Не удалять секции, оставлять пустыми.
- Заметка/идея — короткая страница: заголовок, 1–5 абзацев/буллетов, ссылка
  на источник, связь с проектом через `[[Slug]]`.
- Подборка (`research`) — структурированный ответ на запрос: вопрос, краткий
  вывод, факты с источниками (URL или wikilinks), что не удалось проверить.

## Правила для агента

- Пиши кратко, по-русски, без воды. Это рабочий блокнот, не статья.
- Не выдумывай. Нет источника — пометь «(со слов автора)» или не пиши.
- Wikilinks — по basename без путей: `[[Slug]]`, `[[2026-05-01-idea-x]]`.
- Каждая новая страница — строка в `index.md` в нужной секции.
- `raw/` не трогать. Удаление файлов — только по явной просьбе владельца.
- Делиться с группой (`share_to_chat`) — только когда владелец явно попросил
  («отправь в чат», «поделись с командой», «закинь в main»).
