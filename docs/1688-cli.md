# Поиск на 1688 через 1688-cli

Инструмент агента `search_1688` вызывает [1688-cli](https://github.com/superjack2050/1688-cli)
(MIT, Node 20 + Playwright): поиск товаров по слову и **по фото**, карточка товара (цены по
ступеням, MOQ, характеристики), сравнение, поиск и проверка поставщиков, свои заказы.

**Только чтение.** Команды корзины/оформления заказа/переписки с продавцами/logout агенту
недоступны: аргументы CLI собираются в `bot/agent/one688.py` из белого списка режимов,
свободного ввода нет (тесты — `tests/test_one688.py`).

## Установка на сервере бота (один раз)

CLI работает через настоящий браузер с вашей сессией покупателя 1688.

1. Node.js 20+ (на стенде сейчас v12). Без sudo — через nvm:
   ```bash
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
   source ~/.nvm/nvm.sh && nvm install 20
   ```
2. Сам CLI — по README репозитория (npm-пакет или `git clone` + `npm install && npm run build`).
   Проверка: `1688 doctor --no-launch --json`.
3. Браузер: Google Chrome (рекомендован) или Chromium от Playwright —
   `npx playwright install chromium` (системные библиотеки: `sudo npx playwright install-deps chromium`).
4. **Вход делает человек**: `1688 login` → QR в приложении 1688. Сессия хранится в профиле CLI.
   Бот сам никогда не логинится.
5. В `.env` бота: `ONE688_CLI=/полный/путь/к/1688` (для nvm — путь из `which 1688`, т.к. у бота
   может не быть nvm в PATH), перезапуск бота.

## Если что-то не так

- Агент пишет «сессия 1688 не залогинена» — CLI вернул код 3: повторить `1688 login`.
- «слайдер-капча» — код 4: один раз выполнить запрос вручную с `--headed` и пройти слайдер
  (нужен дисплей / X-forwarding / VNC).
- Запросы идут по одному (общий профиль браузера), таймаут `ONE688_TIMEOUT` (180 с).
- Это парсинг сайта через браузер, а не официальный Open API 1688 (он только для
  корпоративных партнёров): возможны поломки при изменениях сайта и ограничения от 1688.
