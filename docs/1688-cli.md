# Поиск на 1688 через 1688-cli

Инструмент агента `search_1688` вызывает [1688-cli](https://github.com/superjack2050/1688-cli)
(MIT, Node 20 + Playwright): поиск товаров по слову и **по фото**, карточка товара (цены по
ступеням, MOQ, характеристики), сравнение, поиск и проверка поставщиков, свои заказы.

**Только чтение.** Команды корзины/оформления заказа/переписки с продавцами/logout агенту
недоступны: аргументы CLI собираются в `bot/agent/one688.py` из белого списка режимов,
свободного ввода нет (тесты — `tests/test_one688.py`).

### Как авторизовать (один раз, нужен телефон с приложением 1688 или Taobao)

**Вариант 1 — из Telegram (проще):** админ бота пишет боту в личку `/login1688`.
Бот запускает `1688 login` на сервере и присылает картинку с QR → отсканировать в приложении
1688/Taobao → подтвердить на телефоне. Бот ответит «✅ 1688: вход выполнен» (или ошибку —
тогда повторить `/login1688`). QR живёт до 10 минут.

**Вариант 2 — по SSH:**
```bash
ssh builder@10.1.1.156
source ~/.nvm/nvm.sh
1688 login
```
В терминале с TTY QR рисуется прямо в консоли. Без TTY CLI сохраняет PNG в
`~/.1688/login-qr.png` (путь печатается) — его нужно открыть на экране и отсканировать.

Проверка после входа: `1688 doctor --no-launch --json` → `session: ok`; перезапуск бота не нужен
(блок снимается при первом успешном вызове или через 30 минут).

Известное: первый запуск `1688 login` 2026-10-15 упал с `page.goto: Timeout 30000ms` на
`login.1688.com` — разово, повторный запуск отработал и показал QR. Если повторяется — просто
запустить ещё раз.

## Установка с нуля на другом сервере

1. Node.js 20+. Без sudo — через nvm:
   ```bash
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
   source ~/.nvm/nvm.sh && nvm install 20
   ```
2. CLI: `npm install -g 1688-cli` (пакет из репозитория superjack2050/1688-cli). Проверка:
   `1688 doctor --no-launch --json`.
3. Браузер: `npx playwright install chromium` (если не хватает системных библиотек —
   `sudo npx playwright install-deps chromium`).
4. В `.env` бота: `ONE688_CLI=<полный путь из which 1688>` (у процесса бота nvm может не быть
   в PATH), перезапуск бота.
5. Вход — см. «Как авторизовать».

## Если что-то не так

- Агент пишет «сессия 1688 не залогинена» — CLI вернул код 3: `/login1688`.
- «слайдер-капча» — код 4: один раз выполнить запрос вручную с `--headed` и пройти слайдер
  (нужен дисплей / X-forwarding / VNC).
- Запросы идут по одному (общий профиль браузера), таймаут `ONE688_TIMEOUT` (180 с).
- Остановка хода (`/stop`, кнопка «⏹») убивает процесс CLI.
- Это парсинг сайта через браузер, а не официальный Open API 1688 (он только для
  корпоративных партнёров): возможны поломки при изменениях сайта и ограничения от 1688.
