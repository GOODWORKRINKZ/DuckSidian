# Tidy — уборка vault

Работай пакетами, в одном ходе — не больше одного крупного слияния + мелкие правки.

0. ГРАНИЦЫ. Если запущен в теме-воркспейсе — убираешь ТОЛЬКО этот проект: его страницу
   wiki/projects/<Slug>.md и страницы с `project: "[[<Slug>]]"` (или на которые ссылается
   только он). Несколько проектов живут в одном vault — страницы ДРУГИХ проектов (их
   project-страницы, источники, подборки) не правь, не создавай за них и не переноси, даже если
   видишь там дубли/битые ссылки: перечисли их в конце ответа строкой «Для /tidy в теме
   <Проект>: …». Общие index.md/log.md правь только в части своего проекта. Если страница
   по теме явно принадлежит другому проекту (по Решениям/Цели проектов) — не присваивай её
   себе, а предложи перенести (ask_choice).

1. Инвентаризация: list_dir('wiki/research'), list_dir('wiki/sources'), list_dir('wiki/notes'),
   list_dir('wiki/projects'). Сгруппируй страницы по теме по slug/title (одно видео,
   один поставщик, одна тема «карго 2026» и т.п.).
2. Дубли: для группы выбери КАНОНИЧЕСКУЮ страницу (самая полная/ранняя). Перед слиянием
   покажи план через ask_choice: «Слить A, B → C?» с вариантами «да, слить» / «оставить
   как есть» / «другое». После «да»: перенеси уникальные факты в каноническую
   (append_to_section / edit_file), во всех страницах, ссылавшихся на удаляемую, замени
   ссылку (grep_dir('wiki', 'имя-страницы')), затем delete_file дубля, поправь index.md.
3. Противоречия (разные цифры/статусы одного факта): не выбирай сам — ask_choice с
   вариантами-значениями и источниками. Победителя запиши, проигравшее — убери.
4. Страницы проектов > 30 КБ: `## История` перенеси в log.md (append_file), длинные
   разборы — в wiki/research/ со ссылкой, выполненные задачи — убери. В проекте остаются
   Цель / Текущий статус / актуальные Задачи / Решения / Артефакты.
5. Битые ссылки: инструменты записи пишут «⚠️ битые ссылки» — исправляй на существующую
   страницу или снимай [[ ]]. Ссылки в другие воркспейсы/чаты — только текстом.
6. Мусор (страницы-обрывки, slug из текста запроса, тестовые) — удалять только после
   подтверждения в ask_choice.
7. Ответ: что слито/удалено/исправлено (списком путей) и что осталось на следующий заход.
