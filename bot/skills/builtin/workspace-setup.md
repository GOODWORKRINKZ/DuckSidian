# Workspace setup — инструкция воркспейса

Инструкция — это секция `## Инструкция` страницы проекта. Бот даёт её тебе в начале
КАЖДОГО хода, поэтому всё, что должно работать стабильно (а не «пока помнится из
истории»), живёт только там. Записывай через set_workspace_instruction, не через
edit_file/write_file.

1. Пойми суть темы из того, что уже есть: сообщение пользователя, ЗАКРЕПЛЕНО (Цель /
   Текущий статус / Решения), текущая инструкция (если есть), последние реплики истории.
   Если пользователь только что сказал «этот воркспейс про X» — этого обычно достаточно.
2. Неясное уточни через ask_choice — не больше 2 вопросов, с конкретными вариантами из
   материала. Типичные развилки:
   - формат ответа (коротко / разбор / таблица / список с чекбоксами);
   - голос: нужен ли VOICE-блок и ЧТО именно озвучивать (весь ответ / только фразу на
     иностранном языке / краткий пересказ);
   - что делать с каждым входящим сообщением одного типа (чек → таблица трат; репост →
     ответ голосом; ссылка → конспект; слово → карточка с пиньинем);
   - что и куда записывать (страница проекта, wiki/notes, wiki/research) и что НЕ записывать.
3. Составь инструкцию — 5–12 коротких императивных пунктов markdown-списком, по блокам:
   - **Зачем тема** — одна строка.
   - **На каждое сообщение** — что делать с типовыми входами (по типу: текст / голос / фото /
     репост / ссылка).
   - **Формат ответа** — язык, длина, структура, что в VOICE-блоке (если голос нужен).
   - **Запись** — что и куда класть, что держать в «Текущий статус» (рабочая память:
     текущий урок, набор слов, за какой день сведены траты).
   - **Не делать** — чего пользователь не хочет (переспрашивать очевидное, длинные
     простыни, писать в другие проекты).
   Пример пункта: «- Пиньинь и китайское произношение — только в VOICE-блоке, отдельным
   голосовым; в тексте — иероглифы + перевод, без транскрипции».
4. Запиши: set_workspace_instruction(text, mode="replace") при настройке с нуля или
   переписывании; mode="append" — когда добавляешь одно-два правила к живой инструкции.
   Если «Цель» проекта пустая — заполни её одной строкой (edit_file / append_to_section).
5. Ответ пользователю: инструкция списком как записана (он должен видеть, что именно
   закреплено), одна строка «поменять — просто скажи, или /ws prompt».
