# Make skill — создать или обновить скил

Скил — переиспользуемая ПРОЦЕДУРА для разных тем («как делать грилл», «как сводить траты
за день»). Правило для одной темы («в этом воркспейсе отвечай голосом») — не скил, а
инструкция воркспейса (set_workspace_instruction); если пользователь просит именно это —
скажи и сделай через инструкцию.

1. Разберись, что должен делать скил: из слов пользователя и, если он ссылается на «как
   ты сейчас сделал», — из своего последнего ответа и вызванных инструментов в истории.
   Если неясен вход, выход или где остановиться — 1 вопрос через ask_choice, не больше.
2. Имя: латиница, кириллицу транслитерируй, 2–20 символов, `[a-z0-9_-]`, без пробелов —
   оно же команда `/<name>`. Не бери имена команд бота (ws, voice, say, stop, skills,
   share, help, start, model) и встроенных скилов (grill, tidy, interview, workspace-setup,
   make-skill), если не хочешь их перекрыть намеренно.
3. Обновление существующего: сначала read_file('skills/<name>.md') (или use_skill, если
   встроенный — тогда скопируй его в skills/<name>.md и правь копию: vault перекрывает
   встроенный с тем же name). Меняй точечно (edit_file), не переписывай всё без нужды.
4. Формат файла skills/<name>.md (write_file для нового):
   ```
   ---
   name: <name>
   description: <одна строка: что делает и когда применять — по ней агент решает, брать ли скил>
   triggers: «фраза», «фраза», ситуация без явной команды
   ---
   # <Название> — <суть>

   1. Шаг: что прочитать/проверить сначала (ЗАКРЕПЛЕНО, страница, history).
   2. Шаг: действие с конкретным инструментом (ask_choice / append_to_section / …).
   3. …
   N. Ответ пользователю: что показать и в каком виде (сколько строк, что в VOICE).
   ```
   Правила хорошего скила: 4–10 шагов, каждый — действие с инструментом или решение;
   границы («не трогай другие проекты», «не больше 3 вопросов»); куда писать результат;
   формат ответа. Без общих слов («будь полезен»).
5. Проверь: name проходит `^[a-z0-9][a-z0-9_-]{0,40}$`, frontmatter закрыт `---`, тело не
   пустое — иначе скил не загрузится. Строка в index.md не нужна (skills/ — не wiki).
6. Ответ: «Скил `/<name>` готов/обновлён: <description>» + 3–5 строк, что он делает по
   шагам, + «проверь: /<name> <пример>». Не пересказывай весь файл.
